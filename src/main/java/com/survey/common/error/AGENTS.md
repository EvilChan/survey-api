# ErrorCode 定义规范（所有 AI 生成代码必须遵守）

## 1. 位置与引用
- 唯一枚举：`com.survey.common.error.ErrorCode`（禁止再建第二套）
- 业务失败一律：`throw new BizException(ErrorCode.XXX)`，或带 `List<FieldErrorDetail>`
- 禁止：手写错误文案异常、在 Controller/Service 里散落 code 字符串

## 2. 编码规则（字符串码）
- 成功：`SUCCESS` → code `"0"`，httpStatus `200`
- 号段分配（不可越段）：
  - `C0001`–`C9999`：通用/平台级（参数、鉴权、限流、RPC 等）
  - `B0001`–`B9999`：业务错误（枚举内按模块注释分区）
  - `S0001`–`S9999`：系统级（未知异常、依赖故障）
- 同段内按序号 +1 递增，**不跳号、不随意插入**
- 已废弃码禁止复用：标 `@Deprecated`，注释弃用原因与替代码
- `code` 一旦发布永久不可变更

## 3. 命名与字段
- 枚举常量：全大写蛇形，`[动作/状态]_[对象]_[原因]`，如 `USER_NOT_FOUND`
- `identifier`：与常量名相同（成功可用 `OK`），供前端/文档
- `message`：面向终端用户的简体中文，不带 SQL/类名等内部细节
- `httpStatus`：与语义一致（400/401/403/404/409/500…）

## 4. 新增流程（AI 必须按序执行）
1. 搜索项目是否已有同语义错误码 → 有则复用
2. 确定号段，取该段当前最大已用序号 + 1（如最大 `C0001` → 新码 `C0002`）
3. 追加枚举项，写 `/** 使用场景 */`；需前端特殊处理时标注 `【前端动作】`
4. 在 `docs/error-codes.md` 追加一行：`code | identifier | 含义 | 模块 | 日期`

## 5. AI 交付物
新增错误码时必须输出：
- 枚举代码片段（含注释）
- 对照表新增行
- 说明是否需改 `GlobalExceptionHandler`（一般不需要）
